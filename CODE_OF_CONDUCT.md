# Gedragscode

Dit project hanteert de
[Contributor Covenant, versie 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
We verwachten dat iedereen die bijdraagt, of het nu via issues, pull requests of
andere kanalen is, zich daaraan houdt: respectvol, open en inclusief.

Meld ongewenst gedrag aan
[developer.overheid@geonovum.nl](mailto:developer.overheid@geonovum.nl). Meldingen
worden vertrouwelijk behandeld.
